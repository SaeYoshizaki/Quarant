# 最新のファームウェアと更新の記録（2026-11-26）

[一覧に戻る](README.md)

見つかった問題のある機器について、次の 2 つを調べた。

1. 最新のファームウェアがネットで取れるか。
2. 取れないときは、更新の記録（リリースノートなど）に、今回の問題を直したと読める記載があるか。

**決まり**

- 「取れる」は、自分でファイルの URL に HEAD（または先頭だけ取得）を送り、200 とファイルの大きさが返ったもの。
- 機器への操作はしていない。機器の ID やシリアル番号を送る問い合わせもしていない。
- 「（要約）」は、ページの本文が読めず（403 など）、検索結果の要約しかないもの。本文を読んだことにはしない。
- 「修正の記載なし」は、読めた記録に該当する文がないということ。直っていないことの証明ではない。

  - 中身を調べれば、問題の箇所（Sonos の更新の URL、Hue の診断の送り先、Triby の SIP など）が今も平文かを確かめられる。
  - Sonos と HomePod のファイルは暗号化されている可能性がある（未確認）。
- **古い版だけ取れた**：TP-Link HS105 1.5.1、Govee 1.00.10、DCH-S161 1.03.02、DCS-8300LH A1 1.01.04。
  - TP-Link と Govee は、機器が平文で取りに行ったファイルが、今も平文の HTTP で配られている。
- **更新が終わった、または配布元がない**：SmartCam、VeraLite、Withings Home、Wink Hub 2、Awair 第 1 版、DCS-8300LH A1、DCH-S161（第三者）。
  - これらは、収録の時点の問題が残ったままの可能性が高い（推測）。
- **今回の問題を直したと読める記載**：SmartCam の CVE-2018-6295（2018 年 3 月）だけ。それも直した版の番号がない。
- **問題が続いているとみられる手がかり**：
  - Sonos：2025 年の版で更新のファイルを平文で取得（第三者の観測）。
  - TP-Link：最新の版も XOR の旧方式（第三者の記録）。
