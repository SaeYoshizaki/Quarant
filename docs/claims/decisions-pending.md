# 判断待ちの一覧（2026-11-22）

[sweep-handoff.md](sweep-handoff.md) の 4 節の判断待ちを、答えやすい形にまとめた。各行に、選ぶもの、おすすめ、理由を書いた。決めるのは利用者で、ここではまだ何も変えていない。番号で「全部おすすめで」「B3 だけ別」のように答えられる。

済んだもの（2026-11-22）：Withings Home の XMPP（STARTTLS のあと TLS。平文の認証は見えない）、Deakin の Ring（RTP の中身で SRTP と確認）。

## A. 比べる文書の範囲

| # | 判断すること | おすすめ | 理由 |
|---|---|---|---|
| A1 | アプリストアの説明を公式文書に含めるか | 主の表には入れず、参考として別に書く | 製造者が書いた文ではあるが、複数の機種をまとめた宣伝が多い。SimCam の「5MP snapshot」のように、補強には役立つ |
| A2 | 製造者以外が書き、製造者が公開・リンクしている文書（Nest Mini の ioXt 報告、Somfy アプリの opendoors の CGS） | 含める（出どころを note に書く） | 製造者が利用者に示している文書なので、説明として扱える |
| A3 | 単なる取引先の文書（Borun の V380 アプリ、Camcloud、Carematix）、Somfy のフォーラムの社員の回答 | 含めない | 製造者の説明とは言いにくい |
| A4 | 収録の後にしか保存がない文書（Tapo の FAQ 671、Nest のヘルプ、Samsung の PSTI 宣言など） | 使うが「after」と明記し、強い候補の根拠にはしない | 収録の時点の説明だったか確かめられない |
| A5 | 収録よりかなり古い文書（dropcam.com の 2015 年の版、約 21 か月前） | 使う（時期と月数を明記） | 収録の時点でも有効だった可能性が高く、新しい版がない |
| A6 | 地域の版（CIC はカナダ、UNSW・Deakin はオーストラリア、Passive-Mode-Study はフランスも） | 強い候補だけ収録地の版を取り直す。ほかは米国版のまま note に書く | 全部やり直すと時間がかかる。強い候補で版が違うと結論に効く |
| A7 | 文書のない製品で、Tuya のプラットフォームの文書を使うか（TOPERSUN、Perfk） | 使わない（「文書なし」） | 製造者の説明ではない |
| A8 | 著者の文書集（PrivacyPolicyDataset）を出どころに使うか | 今のまま、手がかりにだけ使う | 印刷した PDF で、版の日付が確かめにくい。引用は Wayback から取れる |

## B. 主張の読み方

| # | 製品 | 判断すること | おすすめ | 理由 |
|---|---|---|---|---|
| B1 | Nest Cam（CIC 2021、Passive-Mode-Study） | TLS 1.0 だけで「state-of-the-art security tools」と言えるか | 文言の上での食い違い（T1b）に変える | TLS 1.0 は 2021 年に RFC 8996 で廃止。暗号化はしているので、強い食い違いではない |
| B2 | Govee のケトル | 「state-of-the-art data security tools」と、平文の更新・機器 ID | 文言の上での食い違い（今のまま） | 方法を書かない約束で、比べられるのは言葉だけ |
| B3 | SimCam | 「video」の文に、人物検知の静止画の送信が入るか | 食い違いの候補のまま | 製品ページの「Everything is processed and stored locally」は動画に限っていない |
| B4 | Samsung SmartCam の映像 | 平文の映像を食い違いとするか、「初期値で暗号化されない」とするか | 食い違いの候補として数え、note に「暗号化は任意の設定で初期値オフ」と書く | 仕様の「SSL (AES 256bit)」に条件がない |
| B5 | Samsung SmartCam | 別機種の仕様の行（productId 6502 など）を残すか | 残すが「別機種」と明記し、主の根拠は SNH-P6410BN のデータシートにする | 同じ系列の説明として参考になる |
| B6 | Samsung SmartCam | 2024 年に保存されたマニュアルを、2016〜17 年のものと同じとみなすか | 同じとみなし、note に書く | 2016〜17 年のサポートページが同じファイル名にリンクしている |
| B7 | SimCam | 中国語版のポリシーなど、補助の文書 | 補強にだけ使う | 主の文書（英語の製品ページと FAQ）で候補は成り立つ |
| B8 | Awair | 「TLS and AES 256」の AES 256 が通信か保存か | 候補のまま、note に読み方の幅を書く | 文の並びは通信を指すようにも読める |
| B9 | D-Link DCH-S161 | 「SSL … all logs of settings and Services」に更新の確認が入るか | 弱い候補のまま | 範囲がはっきりしない |
| B10 | Triby | airable が「unaffiliated」に当たるか | 弱い候補のまま | 取引先とする資料があり、どちらとも読める |
| B11 | Ring Alarm | ポートの記事の「HTTP は Base Station に当てはまらない」と接続確認の GET | 文言の上での食い違い（今のまま） | 中身のない接続確認だけ |
| B12 | Somfy | 「AES 256」がゲートウェイの TLS まで含むか | 弱い候補のまま | 単体のページでは Bluetooth の側と書いている |
| B13 | Nest Mini の ioXt 報告、Withings の Data Security | 今の判定（文言の上で、一致） | 今のまま | 新しい材料がない |
