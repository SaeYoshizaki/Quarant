# 人による確認（LLM だけで判断していた部分）

Quarant 自体はルールベースで、解析の途中で LLM を使わない。ただし、研究の作業のうち、研究者が手で判断する部分の多くを Claude が行ってきた。論文の数字がそれだけに頼らないよう、利用者が全件を確認する（2026-10-19 に方針を決めた）。

| ファイル | 中身 | 件数 | 論文の数字への影響 |
|---|---|---|---|
| [A-requirements.md](A-requirements.md) | 要件の分類（E3）：通信を見るだけで何が判定できるか | 78（うち 10 は確認済み） | 最大（「判定できない 71%」） |

確認済み：基準の判定（[../assessment/human-review-accuracy.md](../assessment/human-review-accuracy.md)、36 件、伏せて判定）。
